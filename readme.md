# Neuron Tracing

### Clone the repo and install libraries first
- Copy the github link: https://github.com/kyileiaye2021/Neuron_tracing.git 
- In the terminal, type **git clone [github link]**
- Open the folder with any IDE
- Install libraries with **pip install -r requirements.txt** in the terminal.

### Create enhanced volume
- Run enhance_vol.py
(This will create a tif volume with enhanced contrast version)

### Segment axons
- Run segment_axons.py
(This will create a tif volume with segmented axons)
